{{- /* term-slug.html — reproduce Hugo's internal term -> URL-segment transformation using only template functions. Verified against gohugoio/hugo @ 52c9bd7 (v0.165.0-DEV). Hugo applies TWO passes to a taxonomy term: 1. common/paths.NormalizePathStringBasic (pathparser.go:213) strings.ToLower + " " -> "-" This produces the page's logical .Path (the content-tree key). 2. helpers.PathSpec.MakePathSanitized (helpers/path.go:60) paths.Sanitize -> [removePathAccents] -> strings.ToLower applied per path element in pagePathBuilder.Sanitize (resources/page/page_paths.go:453), then paths.PathEscape. The template function `urlize` is exactly pass 2 plus the escape: URLize(s) = URLEscape(MakePathSanitized(s)) (helpers/url.go:30) So the whole thing collapses to: pass 1 | urlize. Two details that are easy to miss: * The "#" replacement. "#" is an ALLOWED path character in paths.Sanitize, and CreateTargetPaths escapes it to "%23" before parsing the link (page_paths.go:284) so net/url doesn't read it as a fragment. `urlize` calls url.Parse without that guard, so we do the replacement ourselves. "%23" then survives Sanitize, because %XX with hex digits is allowed. * Ordering matters. Doing " " -> "-" BEFORE the disallowed characters are dropped is what produces Hugo's double hyphens: "Rock & Roll" -> "rock-&-roll" -> "rock--roll" Plain `urlize "Rock & Roll"` gives "rock-roll", which is NOT the path Hugo publishes. ARGUMENT: a string (the raw front-matter term value). RETURNS: the URL segment, e.g. "sci-fi". NOTE: assumes the default `disablePathToLower = false`. That setting is not readable from templates (site.Config exposes only Privacy and Services), so if you have enabled it, delete the `replace $s " " "-"` line below — under that flag Hugo uses the unnormalized path, skipping pass 1 entirely, and `urlize` alone is then exact. `removePathAccents = true` is likewise not reproducible here; there is no template equivalent of text.RemoveAccentsString. */ -}} {{- $s := . | default "" -}} {{- $s = replace $s " " "-" -}} {{- $s = replace $s "#" "%23" -}} {{- return urlize $s -}}
