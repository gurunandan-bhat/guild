{{- /* term-url.html — build the full relative URL for a taxonomy term. ARGUMENT: a map with taxonomy (string, required) the PLURAL name, e.g. "tags" term (string, required) the raw front-matter value, e.g. "Sci Fi" lookup (bool, optional, default true) RETURNS: e.g. "/tags/sci-fi/" When `lookup` is true (the default) the partial first asks Hugo for the real term page and returns its .RelPermalink. Prefer this: it is the only version that honours [permalinks.terms], a `url` or `slug` in the term page's front matter, uglyURLs, multihost prefixes and output formats — none of which the string transformation can see. The string path is the fallback, for terms that have no page in this site (external data, a term you are about to write, cross-site links) or when you deliberately want the raw transformation. The plural is passed through `urlize` alone, matching cleanTreeKey (hugolib/content_map.go:485), which is lower(paths.Sanitize(v)) with no space->hyphen pass. */ -}} {{- $taxonomy := .taxonomy -}} {{- $term := .term -}} {{- $lookup := .lookup | default true -}} {{- $url := "" -}} {{- if $lookup -}} {{- with site.GetPage (printf "/%s/%s" $taxonomy $term) -}} {{- $url = .RelPermalink -}} {{- end -}} {{- end -}} {{- if not $url -}} {{- $plural := urlize $taxonomy -}} {{- $slug := partial "taxonomy/term-slug.html" $term -}} {{- $url = relLangURL (printf "/%s/%s/" $plural $slug) -}} {{- end -}} {{- return $url -}}
